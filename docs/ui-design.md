# MANAS 奶油金工作台实施约定

## 模式和真实任务

采用 Migrate，重新设计当前前端壳层及页面。主任务是输入单个数字、执行推理、检查分类与中间激活；辅助详情视图读取现有模型与服务接口。沿用 React、TypeScript、Vite、pnpm、FastAPI，不修改后端契约。配色以用户明确要求的奶油白、香草黄和蜂蜜金覆盖技能的暖灰后备方案。

## 控件清单

### 本轮 Refine：连续淡金纸面

用户反馈上一版黄色过浓且色块割裂。本轮仅调整两页共用的现有视觉 token 与页面 CSS，不改变结构、状态矩阵、接口或交互。页面、导航、输入区与分析区统一为接近白色的 `#fffefa`；去掉工作区圆角外框、输入方式外框、网络层分格与选中行铺色。选中关系使用文字字重和细下划线，淡金仅在主要动作上轻微显现。保留画布、真实数据图像及临时检查器的必要边界，不把内容本身的颜色当作装饰删除。以下控件清单和状态矩阵继续适用。

本轮复验：lint、生产构建和 8 项 Chromium 测试通过（含 axe、配色对比度、响应式及真实模型交互）；人工核对更新后的桌面概率页与 320px 截图。后端未修改，本轮未重复运行 Python 测试。真实屏幕阅读器、物理触屏及跨浏览器人工验收仍未覆盖。

## 页面状态矩阵

| 状态与来源 | 可见信息 | 操作与恢复 | 旧状态处理 |
| --- | --- | --- | --- |
| 首次请求健康状态 | 正在连接 | 可编辑输入，识别暂不可用 | 不推测服务就绪 |
| ready=false | 服务未就绪 | 保留输入，重新检查 | 不显示在线 |
| 健康请求失败 | 连接中断 | 保留输入，重新连接 | 上次结果保留其独立结果身份 |
| 元数据／指标失败 | 区域错误与最后更新时间 | 单区域重试 | 已有数据标记为上次成功快照 |
| 输入为空 | 尚未识别 | 手写或选择文件 | 概率为缺省，不是零 |
| 图片错误 | 文件附近的具体原因 | 重新选择 | 清除旧文件和旧结果 |
| 预测请求中 | 等待结果 | 可取消等待 | 清除上一轮错误及结果，不猜测服务端阶段 |
| 成功 | 真实输出与本次模型 ID | 检查概率和特征 | 成功后窄屏转分析 |
| 取消等待 | 已取消等待，计算可能继续 | 再次识别 | Abort 与请求序号共同拦截迟到响应 |
| 422／503／504／网络失败 | 对应原因及恢复说明 | 修正输入／重试／重新连接 | 保留可重试的输入 |
| 输入或请求参数改变 | 待识别 | 再次识别 | 旧结果立即失效 |
| 未请求中间层 | 本次未获取中间层 | 开启并重新识别 | 不伪造特征 |

输入与参数形成请求快照，只有仍有效的请求可以提交结果；页面切换保留输入和结果，不持久化到服务器或本地存储。统计刷新不触发预测，检查器只读取已有结果。

## 表面、尺度及响应式

语义变量统一管理画布、内容、文字、边界、行动、选择、状态与热图。普通工作面连续无阴影；仅检查器浮层体现高差。正文 15px，辅助文字至少 12px，常规控件 44px、圆角 6px。技术标识使用等宽字体。紧凑的表格行服务数值比较，但可点击目标仍不小于 24px；主要触控按钮至少 44px。

宽屏输入区 320px，分析区占其余宽度；中屏输入区 280px。768px 以下显示输入／分析切换，仅保留当前任务，次要信息放入详情视图。普通页面使用文档滚动；检查器在视口内滚动，数值矩阵允许局部横向滚动。DOM 与视觉顺序一致。

## 验证

真实模型及 API 验证完整输入—预测—检查流程。通过 Playwright 覆盖状态、键盘、焦点返回、hash 导航及视图保留；使用 axe 检查无障碍、用颜色对比计算核对语义 token。检查 320、768、1280、1440px、200% 缩放、触摸和 reduced-motion；保存成功、空内容、错误、详情和移动端截图。分别记录工程检查、真实交互和视觉核查结果，不将构建通过等同于界面验收。
